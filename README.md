# Booming Hub Shenzhen Article Review Desk

Public review surface for the Booming Hub Shenzhen recruitment article.

- Edit text in place while keeping the WeChat layout fixed.
- Replace, delete, or restore each image; image actions are included in the change list and handoff link.
- Receive a freshly rendered header or recruitment poster from the Booming poster studio and place it in the corresponding article slot.
- Apply bold or the approved blue, black, and gray text colors.
- Track text-only and formatting-only changes by paragraph.
- Generate a self-contained handoff link encoded in the URL fragment.
- Copy one revised block, the complete change list, or the full rich-text body.

The shared review payload stays in the URL fragment and is not sent to a backend.
